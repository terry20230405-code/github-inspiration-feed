## 设计边界

阶段八使用两层保护：

1. Git 保存前端、Skill、脚本、文档和确认后的数据里程碑。
2. 刷新快照保存自动刷新有权修改的 6 个固定 JSON 文件与所有 `*.source.json`。

自动刷新不运行 `git reset --hard`，不会覆盖工作区中的其他修改。`editorial.ts`、`visuals.ts`、AI 审核和候选草稿不属于刷新回滚范围。
