# App-ready project schema

Output UTF-8 JSON containing one versioned project record. The record separates automatically refreshable repository facts, stable editorial content, and persisted visual configuration so one update cannot silently overwrite another layer.

```json
{
  "schemaVersion": 2,
  "id": "repository-slug",
  "repository": {
    "githubId": 123456789,
    "fullName": "owner/repository",
    "name": "Repository name",
    "stars": 12345,
    "forks": 1234,
    "language": "TypeScript",
    "pushedAt": "2026-08-27T08:00:00Z",
    "license": "MIT",
    "state": "active",
    "fetchedAt": "2026-08-27T09:00:00Z"
  },
  "editorial": {
    "hook": "没有句号的创意副标题",
    "summary": "两句话的高信息密度产品介绍。说明核心操作、主要功能和结果。",
    "meaning": "为什么这些基础能力适合继续改造成新产品。",
    "audience": "原项目的主要用户",
    "features": ["核心功能一", "核心功能二", "核心功能三"],
    "stack": ["主要技术一", "主要技术二"],
    "opportunity": ["具体拓展依据一", "具体拓展依据二", "具体拓展依据三"],
    "directions": [{
      "id": "direction-slug",
      "name": "具体产品方向",
      "tagline": "输入什么并得到什么",
      "problem": "目标用户遇到的具体重复问题。",
      "audience": "明确的目标用户",
      "approach": "第一版如何复用原项目能力并形成完整流程。",
      "difference": "与原项目在用户、流程或结果上的实质差异。",
      "scope": ["最小功能一", "最小功能二", "最小功能三"]
    }]
  },
  "visual": {
    "generatorVersion": 2,
    "seed": "owner/repository",
    "accent": "#315e88",
    "foreground": "#ffffff",
    "motif": "network",
    "variant": 18427
  }
}
```

## Layer responsibilities

### `repository`

This layer is replaced by deterministic GitHub refreshes. Store raw values rather than display strings:

- `githubId` is GitHub's numeric repository ID and remains the identity anchor across renames or transfers.
- `fullName` is the current `owner/repository`; the frontend derives the GitHub URL from it.
- `stars` and `forks` are non-negative integers, never abbreviated strings such as `12.3k`.
- `pushedAt` is the latest GitHub push time in UTC ISO 8601 format, never relative text such as `2 天前`.
- `fetchedAt` records when this snapshot was collected.
- `pushedAt` cannot be later than `fetchedAt`; a snapshot cannot contain a repository event from after it was collected.
- `license` stores the verified display label. Use `未知` when neither GitHub nor the official license file establishes it. Preserve custom labels such as `Remotion License` or `Sustainable Use License` instead of converting them to `MIT`.
- `state` is `active`, `archived`, `disabled`, or `unavailable`.

A metadata-only refresh changes this layer and leaves `editorial` and `visual` byte-for-byte unchanged.

### `editorial`

This layer contains reviewed Chinese copy and directions. It changes only after a meaningful repository change or an editorial revision. Field responsibilities and page mapping are defined in [content-contract.md](content-contract.md).

### `visual`

This layer contains the complete persisted product visual identity. It is generated by the product, not extracted from GitHub, and a repository refresh must not change it. `seed`, `motif`, and `variant` make the result reproducible; `generatorVersion` prevents later algorithm changes from silently restyling old cards. Generation rules are defined in [visual-identity.md](visual-identity.md).

## Constraints

- `schemaVersion` is exactly `2` for this shape.
- Project and direction IDs use lowercase kebab-case.
- Include 3–5 unique directions and 3–6 scope items per direction.
- Include 3–6 features, 1–8 stack items, and 2–5 opportunity items.
- Do not include the removed `category`, `difficulty`, or `duration` fields.
- `visual.generatorVersion` is `1` or `2`; new identities use `2`, while persisted version-1 identities remain valid. `visual.variant` is an unsigned 32-bit integer.
- `visual.seed` uses canonical `owner/repository` form at identity creation time and remains stable after repository renames.
- `visual.accent` is a six-digit hex color with at least 4.5:1 contrast against white.
- `visual.foreground` is `#000000` or `#ffffff`, whichever has stronger contrast on the accent.
- `visual.motif` is `orbit`, `network`, `wave`, `radial`, `stack`, `grid`, `path`, or `polyline`.
- Display formatting belongs to the frontend. Do not store abbreviated counts, relative dates, or a duplicated GitHub URL in the record.

The three layers match the `Project` type and source files under `src/data/`. Published repository snapshots are stored in `src/data/repositories.json`, validated by `src/data/repositories.ts`, and refreshed according to [refresh-workflow.md](refresh-workflow.md).
